# E-Commerce Sales Analysis

## Overview
End-to-end data analysis of e-commerce order data identifying 
revenue trends, customer insights and product performance 
using Python, SQL and Power BI.

## Business Questions Answered
1. Which region generates highest revenue?
2. Which customers are most valuable?
3. What is the monthly revenue trend?
4. Which product category performs best?
5. What is the order completion rate per region?

## Key Findings
- Electronics drives **81%** of total revenue
- **Bob Smith** is highest value customer at $9,150
- **North region** has 100% order completion rate
- **February** was strongest revenue month
- Revenue declined **30% MoM** in April
- 2 duplicate orders removed during cleaning
- 1 data quality issue found — Laptop price corrected

## Tools Used
| Tool | Purpose |
|---|---|
| Python (pandas) | Data cleaning and analysis |
| Matplotlib / Seaborn | Exploratory visualizations |
| SQL (SQLite) | Data querying |
| Power BI | Dashboard and reporting |
